## Как подрубить проект

**Что нужно иметь:**  Node.js, пакет разработки Java (не обязательно)


1. Установи зависимости:
   `npm install`
2. Установи `GEMINI_API_KEY` в [.env.local](.env.local) как твой Gemini API ключ. (если ты мажор)
4. Для  нищих - скачай проект, открой его как проект в IDE (чтобы был доступен терминал), далее меняй файлы и коммить, обновляй Gemini AI, она рекомпелирует файлы
3. Открыть проект:
   `npm run dev`
